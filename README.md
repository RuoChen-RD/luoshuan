# 螺栓已拧 ROI 检测原型

这是一个固定相机、固定点位的浏览器原型。打开 `index.html` 后会加载 `assets/sample-board.png`，并以这张图的像素坐标作为标准 ROI 点位；蓝色或金属垫片不算螺栓，只有检测到上方黑色螺栓头才判定为已拧上。

## 使用方式

1. 直接用浏览器打开 `index.html`。
2. 点击“重新检测”查看当前样图结果。
3. 如果圈仍有轻微偏移，点击“按当前图校准点位”，系统会在当前固定点位附近吸附圆心。
4. 勾选“编辑点位”后，在图片上拖动 ROI 圆圈微调坐标。
5. 右侧可修改点位编号、坐标、半径和检测目标。
6. 点击“应用修改”或拖动结束后，点位会自动保存到浏览器本地，刷新页面仍会保留。
7. 导入新图片时，图片需要和 `sample-board.png` 保持同机位、同角度、同分辨率；系统会按固定坐标直接检测。
8. 点击“保存点位文件”可把当前点位写入 `bolt-layout.json`。
9. 点击“打开点位文件”可读取之前保存的点位 JSON，并继续编辑。
10. 点击“恢复默认”可清除本地保存的点位，回到内置点位。
11. 点击“导出结果”保存本次检测结果 JSON。

注意：`file://` 打开和 `http://` 打开使用的是不同的浏览器本地存储空间。现场调试时建议固定使用同一种打开方式。

如果浏览器支持 File System Access API，页面会直接写入你选择的 JSON 文件；如果不支持，会自动退回为下载 JSON 文件。

## 现场落地流程

1. 固定相机、镜头、曝光、白平衡和光源。
2. 以 `sample-board.png` 为标准图，标定所有孔位/垫片中心的 ROI。
3. 后续图片必须保持同一拍摄位置和分辨率，系统直接使用固定像素坐标检测。
4. 所有点位默认都参与检测，垫片位置没有黑色螺栓头时判定为未拧。
5. 先用规则阈值跑一批真实图片，统计误判点。
6. 优先调整“最小黑色占比”“最小深黑占比”和 ROI 中心位置；当前算法会识别白色/蓝色垫片，只有垫片但深黑螺栓头不足时判为未拧。

## 判断逻辑

- `已拧`：ROI 中心核心区检测到足够的黑色螺栓头。
- `复核`：检测到黑色区域，但信号偏弱、面积过大或位置偏心，可能是污渍、反光、拧偏或 ROI 未对准。
- `未拧`：中心核心区黑色螺栓头占比过低，或垫片占比很高但没有足够深黑螺栓头。
- `忽略`：人工跳过该 ROI，不参与检测。

单个俯视相机只能做贴合的间接判断。若贴合高度要求严格，建议增加低角度侧光、侧相机或激光测高；当前原型适合作为第一阶段的固定坐标 ROI 检测。

## 误判处理

如果已拧点大量显示为复核，通常是螺栓头高光导致黑色区域偏到一侧，可以适当降低“最小黑色占比”或放宽“最大偏心”。如果只有白色/蓝色垫片的位置显示为已拧，说明深黑头信号阈值过松，应提高“最小深黑占比”；当前默认值为 `0.16`，并额外加入了“垫片占比高但深黑螺栓头不足”时直接判未拧的规则。
