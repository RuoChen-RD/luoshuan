# 枪头关键点标注说明

## 标注目标

每张图片最多标注一把拧紧枪：

- 框：包住整把拧紧枪主体，尽量包含批头和枪灯，不要把手臂或整只手包进去。
- 关键点 `tip`：放在真正接触螺丝的批头最末端，不是枪体中心、灯中心，也不是枪杆中点。

## 标注规则

- 批头清晰可见：标注关键点可见性 `2`。
- 批头被手或板件部分挡住，但根据枪杆方向可以确定末端：标注可见性 `1`。
- 只有枪头/枪杆露出、枪身被画面裁掉：仍然标注为正样本；框住可见的枪头/枪杆部分，关键点放在可判断的批头最末端。
- 只有一个很短的黑点或末端方向无法判断：该帧不标注实例，保留为负样本。
- 画面中没有拧紧枪：该帧保留为空标签文件，作为负样本。
- 同一画面只出现一把枪时只标注一个实例；不要标注螺丝、手、灯或板上孔位。

## YOLO pose 标签格式

每个实例一行，共 8 个字段：

```text
0 cx cy width height tip_x tip_y visibility
```

所有坐标都归一化到 `0` 到 `1`。例如：

```text
0 0.57 0.22 0.18 0.34 0.56 0.39 2
```

图片和标签必须同名：`frame_00001.jpg` 对应 `frame_00001.txt`。负样本需要创建同名空 `.txt` 文件。

## 数据划分

按视频段划分训练集和验证集，不要把同一段视频相邻帧随机拆开。建议：

- `train`：约 80%
- `val`：约 20%

第一批建议至少 800 张标注帧；现有 `拧紧.mp4` 已抽取 143 张待标注帧，适合先跑通流程，但不足以代表全部现场情况。

导出 YOLO 标签后，可将未标注帧按负样本补齐并按视频时间顺序划分：

```bash
.venv/bin/python scripts/prepare_pose_dataset.py --missing-as-negative
.venv/bin/python scripts/validate_pose_labels.py
```
